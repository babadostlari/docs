# Baba Dostları Derneği Sitesi

Baba Dostları Derneği için hazırlanmış kurumsal ve haber sitesi.

Aşağıdaki sayfaları kullanarak site içeriğinizi güncelleyebilir ve yerel önizleme yapabilirsiniz.

## Geliştirme

Mintlify önizlemesini çalıştırmak için Mintlify CLI'yi yükleyin:

```
npm i -g mint
```

Daha sonra proje kökünde şu komutu çalıştırın:

```
mint dev
```

Yerel önizlemeyi `http://localhost:3000` adresinde görüntüleyin.

## Site içeriği

- `index.mdx`: Ana sayfa
- `hakkimizda.mdx`: Dernek ve kurumsal bilgiler
- `haberler.mdx`: Güncel haberler ve duyurular
- `iletisim.mdx`: İletişim bilgileri
- `destek.mdx`: Üyelik, gönüllülük ve bağış bilgileri

## Yayınlama

Değişikliklerinizi commit ve push ederek projeyi güncelleyebilirsiniz.

## Yardım

- Eğer sayfa 404 hatası veriyorsa, `docs.json` dosyasının kök dizinde bulunduğundan emin olun.
- Mintlify CLI sorunları için `npm i -g mint` ile CLI'yi güncelleyebilirsiniz.
