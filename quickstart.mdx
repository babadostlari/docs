## Üç adımda başlarken

Siteyi yerel olarak çalıştırın ve ilk özelleştirmelerinizi yapın.

### Adım 1: Yerel ortamınızı kurun

<AccordionGroup>
  <Accordion icon="copy" title="Depoyu yerel olarak kopyalayın">
    Bu sitenin kaynak kodunu GitHub'dan kopyalayarak düzenlemeye başlayabilirsiniz.

    Yerel kopyayı almak için GitHub deposunu klonlayın ve bu klasörde çalışın.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Önizleme sunucusunu başlatın">
    1. Mintlify CLI'yi yükleyin: `npm i -g mint`
    2. Docs klasörünüzde çalışın ve `mint dev` komutunu çalıştırın.
    3. `http://localhost:3000` adresini açın.

    <Tip>Dosyaları kaydettiğinizde site otomatik olarak güncellenir.</Tip>
  </Accordion>
</AccordionGroup>

### Adım 2: Değişiklikleri yayınlayın

<AccordionGroup>
  <Accordion icon="github" title="GitHub entegrasyonunu kullanın">
    Değişiklikleri GitHub üzerinden yönetiyorsanız, GitHub entegrasyonu ile otomatik deploy sağlayabilirsiniz.
  </Accordion>
  <Accordion icon="palette" title="Site adını ve renkleri güncelleyin">
    İlk değişiklik olarak site adını ve renk paletini düzenleyin.

    1. `docs.json` dosyasını açın.
    2. `"name"` alanını dernek adınızla değiştirin.
    3. `"colors"` alanını markanıza uygun renklerle güncelleyin.
    4. Kaydedip `http://localhost:3000` adresinde sonucu görün.

    <Tip>Birincil rengi değiştirerek hemen farkı görün.</Tip>
  </Accordion>
</AccordionGroup>

### Adım 3: Yayına alın

<Accordion icon="rocket" title="Sitenizi yayınlayın">
  1. Değişiklikleri commit ve push edin.
  2. Site kısa süre içinde güncellenecektir.
</Accordion>
