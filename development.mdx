<Info>
  **Gereksinimler**:
  - Node.js 19 veya üzeri
  - `docs.json` dosyası bulunan bir docs deposu
</Info>

Mintlify'i yüklemek ve çalıştırmak için şu adımları izleyin.

<Steps>
<Step title="Mintlify CLI'yi yükleyin">

```bash
npm i -g mint
```
</Step>

<Step title="Yerel önizleme">

`docs.json` dosyasının bulunduğu klasörde aşağıdaki komutu çalıştırın:

```bash
mint dev
```

Bu komuttan sonra `http://localhost:3000` adresinde yerel önizlemeyi görebilirsiniz.

</Step>
</Steps>

## Özel portlar

Varsayılan olarak Mintlify port 3000'i kullanır. Başka bir port kullanmak için `--port` bayrağını kullanabilirsiniz. Örneğin:

```bash
mint dev --port 3333
```

Eğer port zaten kullanımda ise, Mintlify bir sonraki kullanılabilir porta geçecektir.

```md
Port 3000 zaten kullanımda. 3001 numaralı porta geçiliyor.
```

## Mintlify sürümleri

CLI sürümünüzün güncel olduğundan emin olun. Yerel önizleme ile üretim sürümü farklı ise CLI'yi güncelleyin:

```bash
npm mint update
```

## Link doğrulama

Bağlantı doğrulamak için aşağıdaki komutu kullanabilirsiniz:

```bash
mint broken-links
```

VSCode kullanıyorsanız [MDX VSCode uzantısını](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) ve [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) kullanabilirsiniz.

## Sorun giderme

<AccordionGroup>
  <Accordion title='sharp modülü yüklenemediğinde'>

    Bu sorun eski Node.js sürümünden kaynaklanabilir. Şu adımları uygulayın:
    1. Mevcut CLI sürümünü kaldırın: `npm remove -g mint`
    2. Node v19 veya üzeri yükleyin.
    3. CLI'yi tekrar yükleyin: `npm i -g mint`
  </Accordion>

  <Accordion title="Bilinmeyen bir hata alınıyorsa">
  
    Çözüm: Cihazınızın kök dizininde `~/.mintlify` klasörünü silin. Ardından `mint dev` komutunu tekrar çalıştırın.
  </Accordion>
</AccordionGroup>

Son CLI güncellemelerini görmek için [CLI değişiklik günlüğüne](https://www.npmjs.com/package/mintlify?activeTab=versions) bakabilirsiniz.
